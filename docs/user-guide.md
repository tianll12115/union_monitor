# 使用指南

看板的筛选、统计口径与导出约定，用于理解查看结果的含义。项目简介与快速开始见 [项目入口](../README.md)。

## UBS

- 列表搜索只定位 PR，不改变 KPI / 趋势；状态、完整性、触发类别筛选会改变统计样本。
- 排序支持代表 E2E、批次数、创建时间；排队 / 执行 / 总计切换任务指标列。

## Triton

- 分支和时间范围控制全页分析范围；每张图的状态按钮只改变该图及图内统计。
- 列表搜索只改变列表和导出集合；关注按批次去重，同批次可有多个原因标签。

## E2E 口径

E2E 不跨项目混算：

- **UBS**：每 PR 取最长合格 E2E 的代表批次，并列按 trigger 编号和 URL 决定；x86 / ARM / DT 均取该批次内唯一、关联有效的终态任务。
- **Triton**：按提交及重跑 attempt 形成批次，只有成功 / 失败且耗时有限非负、E2E 关联资格有效的批次进入终态分位数；未关联 PR 的观测记录仍保留，NPU 资格独立判断。

## 时间与统计约定

- UBS 排队 = `waiting + blocked + buildable`，总计 = 排队 + 执行；缺失分项留空。
- 取消处理保留各项目口径，不能统一当失败或统一排除。
- 空值不补零，合法 0 保留；P90 使用 `(n−1)×0.9` 线性插值，是样本分位数，不是 SLA。

## 导出

- CSV 仍保留各项目原字段与单位（UBS 毫秒、Triton 秒），分页 / 折叠不截断导出。
- Triton 另下载 `triton-qualifications-v1.json` 说明每批次资格，这不是完整统一导出格式。
- 本地 CSV 保存到 `web/exports/`，资格 JSON 由浏览器下载；Pages 上两者均由浏览器下载。

## 工作台

「重新加载快照」只读取已发布文件，不触发采集。页面使用各快照的原采集时间；读取失败时会提示，并尽可能保留已加载的有效数据。当前工作台未接入统一运行报告、发布版本和跨项目关注聚合，不能用它判断本轮采集成功或“没有关注记录”。
